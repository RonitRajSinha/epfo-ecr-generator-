# EPFO ECR Generator

A simple tool to make EPFO ECR file preparation easier.

## About

Preparing an EPFO ECR file can involve a lot of repetitive work — handling employee data, formatting records, and making the final TXT file ready for upload.

I wanted to make this process simpler by building a tool that reduces the hassle of working with Excel and Notepad just to prepare an upload-ready file.

The goal is to make ECR preparation quicker, simpler, and less repetitive.

## What I'm Building

- A simple way to enter employee data.
- A way to generate a TXT file in the required ECR format.
- A cleaner workflow with less manual formatting.
- A straightforward interface that's easy to use.

## Built With

- HTML
- CSS
- JavaScript
